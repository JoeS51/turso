Working Glossary

Wire layer. The code that accepts PostgreSQL protocol messages and builds protocol responses. In this repository, mainly postgres/server plus the pgwire dependency.

Frontend layer. The PostgreSQL compatibility code between a client and Turso core. It includes server, session, parser, translator, catalogs, aliases, and PostgreSQL-specific tests.

Translator. Converts the protobuf AST produced by PostgreSQL's parser into Turso's parser AST. It is not the query planner.

Core boundary. The call that hands a translated ast::Cmd to Turso core and receives a compiled Statement.

Command tag. The string in CommandComplete, such as SELECT 1 or INSERT 0 3.

Compatibility Watchpoints

The current simple-query handler buffers encoded rows before returning a response. It also executes split statements one by one rather than adding PostgreSQL's implicit transaction around a multi-statement simple query. Treat these as observed implementation facts, not as desired protocol semantics; compare behavior with the PostgreSQL simple-query specification before changing related code.
