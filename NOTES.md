# Teaching Notes

- Goal: contribute code to Turso's PostgreSQL frontend.
- Starting point: knows PostgreSQL concepts, new to Turso internals.
- Prefer one request path at a time, with source links and a contribution-oriented test decision.
- Break each request path down into byte, crate, and function handoffs before presenting the larger architecture.
- Prefer one-question-at-a-time teach-back quizzes where the learner answers freely before receiving corrections.
