# Distinguished statement preparation from execution

The learner understands that normal preparation compiles a translated Turso AST into a `Statement` containing a VDBE program, but does not yet produce selected rows or apply inserted rows. Execution later runs that program and produces its effects, so future lessons can build on prepared statements, parameters, metadata, and VDBE stepping.

## Evidence

After correcting an initial prepare-versus-result confusion, the learner explained the distinction from memory for both `SELECT` and `INSERT`.
